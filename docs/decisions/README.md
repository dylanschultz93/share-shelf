# Decisions

One file per decision, numbered in the order they're made: `0001-short-name.md`.

Keep each one short:

```markdown
# 0001: Short title

**Status:** Decided (YYYY-MM-DD)  <!-- or Superseded by 00NN -->

## Question
What we had to decide, in a sentence or two.

## Decision
What we picked.

## Why
The reasons, and the options we passed on.

## What this affects
Downstream questions this settles or changes.
```

When a decision is made, check it off in [`../open-questions.md`](../open-questions.md) and link it here.
