# 0007: Show full names

**Status:** Decided (2026-10-02)

## Question
What should people see about each other?

## Decision
- **Full names, visible to everyone in the app.** For example, "Sam Kowalski is bringing 3 Play-Doh" or "Wooden train set from Jess Park."
- **We ask for a name during first-time setup** (screen 1b), along with role and rooms.

## Why
- It helps build community. CECC is small, and people know each other or should.
- The app is already limited to approved people ([0002](0002-who-gets-in.md)), so names are only visible inside the school community.

## What this affects
- Each account stores a name as well as an email.
- People can edit their own name. Admins can fix names too.
- Profile photos and a directory were suggested but deferred. See [ideas-for-later.md](../ideas-for-later.md).
