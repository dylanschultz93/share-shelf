# How big CECC is

From the founder (2026-10-02).

| | Count |
|---|---|
| Children (capacity) | 120 |
| Families | Fewer than 120 because of siblings. Estimate **about 100–110** |
| Classrooms | 11 |
| Teachers | 3 per room at all times: 11 leads, 11 full-time support, 11+ part-time support or floaters. About **33–40** |
| Admin and leadership | 4 |

**Total possible users:** about 100–110 families (1–2 adults each) plus about 40 staff, so **roughly 150–260 people.**

**What this means technically:** this is very small. Any database, host or sign-in service handles it easily, including free tiers. Data volume won't drive any decision. Photos are the only thing that takes up real space, and that's manageable if we shrink them when they're uploaded.
