# Principles

Rules of thumb we've agreed on. Use them to settle smaller questions without a full discussion.

1. **The school runs it, and it has to be easy.** Anything an office admin has to do should be as easy as editing a Squarespace page. See [decision 0001](decisions/0001-school-runs-it.md).
2. **Don't build features to police behavior until it's a real problem people are running into.** For example, no "allowed items" rules or approval steps on posts up front. Trust the community, give admins a way to remove a post, and add more only when real use shows we need it.
